# CCMines
A version of Minesweeper for Computercraft.

<img width="1920" height="1200" alt="2026-10-05_17 33 12" src="https://github.com/user-attachments/assets/fa882677-a433-4900-a5b7-8854b19b0036" />


This is a full version of Minesweeper for ComputerCraft/CC:Tweaked.
Current features include:
- 3 difficulty options
- Randomly placed mines
- Win/lose detection

Planned features:
- Custom map size
- Better mine spreading

Controls:
- **Left mouse button:** uncover tile
- **Right mouse button:** place/remove flag
- **Middle mouse button:** uncover all surrounding tiles

Install:
- **run:** wget https://raw.githubusercontent.com/bennybest7/CCMines/refs/heads/main/ccmines.lua
